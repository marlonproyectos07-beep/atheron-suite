# Decisiones de orquestación

## D-001 — GitHub es la fuente única de verdad
Las conversaciones son temporales; commits, ramas y archivos de estado son persistentes.

## D-002 — No comprar otra suscripción por ahora
Primero se probarán alternativas ya disponibles, gratuitas, open source o locales antes de añadir otro coste fijo.

## D-003 — Arquitectura multiagente con relevo
Claude Code sigue como constructor principal; ChatGPT actúa como director/auditor; se incorporará un agente C de respaldo y un agente local/económico.

## D-004 — Producción queda fuera de esta fase
La creación de la capa de orquestación no cambia la web, DNS, Vercel, CMS ni contenido público.

## D-005 — Modelos premium solo para trabajo premium
Los cambios rutinarios deben desviarse a agentes más económicos o locales cuando sea posible.


## D-006 — El navegador no puede ser dependencia crítica
La operación hotelera multiagente no debe depender de una pestaña Chrome autenticada de un proveedor específico. El objetivo de HOTEL-007 es una interfaz técnica persistente de mínimo privilegio.

## D-007 — Sin gasto nuevo como requisito para avanzar
La arquitectura, documentación, auditorías públicas, GitHub y preparación técnica deben continuar con herramientas ya disponibles. Nuevos créditos/suscripciones son aceleradores opcionales, no condición para que el proyecto avance.
